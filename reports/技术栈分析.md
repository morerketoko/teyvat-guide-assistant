# 「提瓦特浏览器」(Teyvat Browser) 项目技术栈报告

## 一句话概况

一个基于 **Electron 27** 的 Windows 桌面浏览器工具（原神游戏内嵌置顶浏览 + B站视频控制），核心卖点是用了 **C++ 原生模块（node-addon-api）** 实现「UIAccess 高级置顶」和全局快捷键——这是普通 JS 做不到的部分。

## 技术栈清单

| 层 | 技术 | 说明 |
|---|---|---|
| 桌面框架 | **Electron ^27** | 主进程 `src/main/main.js`，预加载 `src/main/preload.js` |
| 渲染层 | **原生 HTML/CSS/JS** | 无前端框架（无 React/Vue/Vite），控制台界面 `src/renderer/index.html` + `renderer.js` |
| 原生模块 | **C++ / node-gyp / node-addon-api** | `src/native/`，两个模块：`high_priority_shortcut`（全局快捷键）、`high_priority_topmost`（UIAccess 置顶） |
| 持久化 | **electron-store ^7** | 收藏夹、缩放级别、窗口位置、快捷键设置 |
| 打包 | **electron-builder ^24** | Win(portable + dir)、mac(dmg)、linux(AppImage/deb)，`appId: com.teyvat.browser` |

## 关键特征

1. **无现代前端工具链**：纯 JS 渲染进程，没有打包器、没有 TypeScript、没有测试框架（`npm test` 是占位符）。
2. **原生模块是核心亮点**：`binding.gyp` 编译出 `high_priority_shortcut.node` 和 `high_priority_topmost.node`，通过 `extraResources` 打进 `app.asar.unpacked`，构建需 `node-gyp rebuild`（即 `npm run build-native`）。
3. **依赖极少**：运行时依赖只有 `electron-store` 一个。
4. **游戏场景设计**：Insert 显隐窗口、F1/F2/F3 控制 B站播放器、Ctrl+↑/↓ 调透明度、全屏游戏置顶不触发反作弊（需管理员权限运行）。
5. **构建脚本**：`npm run build:win` / `build:portable`；`npm start` 直接以 `electron .` 运行。

## 目录结构

```
Teyvat_Browser/
├── src/
│   ├── main/main.js + preload.js   # Electron 主进程
│   ├── native/                     # C++ 原生模块（binding.gyp）
│   └── renderer/                   # 控制台 UI（原生 JS）
├── dist/                           # 构建输出
└── package.json
```

## 给 ChatGPT 的提示要点

- 这是 **小型个人开源项目**（ISC 协议），代码规模小、结构直白，适合整体理解后直接改。
- 改动原生模块后需要重新 `node-gyp rebuild`，且二进制 `.node` 已编译过（win32-x64, Node 118 对应 Electron 27）。
- 渲染进程与主进程通信走 preload + ipc，没引入额外安全框架。
- 当前版本 v0.2.0，功能：收藏夹、页面缩放、全局快捷键、高级置顶、窗口位置记忆。
